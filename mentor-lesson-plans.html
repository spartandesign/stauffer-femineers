Prototype the Future

Students build the smallest real version that can answer an important technical or design question.

Room 14 · Monday bell schedule · 8:00 a.m.–2:41 p.m.

Prototype EvidencePrototype, test record, first-test note, mentor decision

Prepare before October 5

  • Verify approval status; prepare a revision table for students who are not cleared to build.
  • Inventory, test, label, and release only the supplies needed for today’s small prototypes.
  • Set wearable stations for paint/material tests, one-light circuit swatches, and prepared NeoPixel programming.
  • Set robotics stations with numbered Premium Kits, iPads, craft materials, and component menus.
  • Prepare one successful and one intentionally flawed test example for each pathway.

  • I can identify the exact construction step I am ready for next.

Build & Test

Students continue construction, troubleshoot with evidence, and secure a clear restart plan before winter break.

Room 14 · Monday bell schedule · 8:00 a.m.–2:41 p.m.

Mid-Build EvidenceTest result + next-step plan

Prepare before December 7

  • Use Checkpoint 2 to sort projects into build, repair, retest, and mentor-conference groups.
  • Inspect stored projects for damage, wet paint, loose stitches, discharged batteries, bent parts, and missing labels.
  • Prepare troubleshooting cards: observe, power off, check one thing, retest, record.
  • Set up a repair station and a separate inspect bin for questionable electronics.
  • Prepare wearable hat-mounting mockups and robotics subsystem test spaces.

Student learning targets

  • I can test one subsystem with a clear success condition.

  • I can repair or improve work without hiding the problem.
  • I can store the project safely for the long break.
  • I can write a January restart instruction that is specific and useful.
