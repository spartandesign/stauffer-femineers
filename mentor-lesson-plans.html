Mentor background and rehearsal before September 14

Wearables concepts every station lead must know

  • Future Stamp: ordinary embroidery floss is decorative and nonconductive. No LED, conductive thread, or battery belongs at that table.
  • Circuit Lab: the battery provides energy; a complete positive path through the LED and a separate negative return path are both required. Match + to + and − to −. The paths must never touch.
  • micro:bit: wearable boards are labeled W and use MakeCode on Windows laptops. Buttons are inputs, event blocks decide, and the display is an output.
  • NeoPixel: the strip is a three-wire addressable system. P0 data enters DIN in the arrow direction; the micro:bit and pixels use separate positive power and a shared ground; students never rebuild the harness.
  • Evidence: a clear in-progress photo or screenshot plus a short explanation is more valuable than rushed “finished” work.

Robotics concepts every station lead must know

  • Hummingbird system: the controller links a robotics micro:bit, sensors, LEDs, servos, and other outputs.
  • Firmware boundary: robotics boards are labeled R and keep BirdBrain Bluetooth firmware. Never load a MakeCode program onto them.
  • Interaction: an input senses or receives information; BirdBlox applies a rule; at least two outputs respond; reset returns the system to a safe ready state.
  • Connection identity: teams select only the assigned three-word device name and verify the green connection dot before running code.
  • Roles: Driver operates the current device/build step; Navigator reads the card, checks ports and safety, predicts, and records. Both explain the result.

Required mentor practice

Every station lead completes the core student workflow before leading it. Run one timed mock rotation using the actual materials, devices, batteries, laptops, cables, needles, station card, and evidence process.

  • Set up labeled READY → BUILD → CHECK → EVIDENCE → RETURN areas.
  • Teach the station using its one-sentence anchor phrase without adding a long lecture.
  • Complete the required core task and evidence within 25 minutes.
  • Diagnose one planted common failure without changing several variables at once.
  • Run the exact three-minute transition, including needle count or powered-system shutdown.
  • Reset the station so an incoming group can begin without searching for parts.
  • Identify the backup task for network, device, supply, or staffing failure.

If a mentor cannot independently teach, troubleshoot, account for, and reset the station: add training, pair that person with an experienced lead, reduce capacity, or simplify the student task before the workday.

Wearables Station 2 · LED + conductive-thread Circuit Lab · 25 minutes

Right-size this rotation: the full LED and conductive-thread tutorials are larger than one beginner 25-minute station. Objective and mentor anchor

Prepare

Creative Robotics lane · four sequential Hummingbird challenges

Teams rotate roles—not hardware: every pair stays at one table with one numbered Hummingbird kit, its R-labeled micro:bit, assigned iPad, recorded device name/initials, and prewired capability board. Controller knowledge is required before the input, output, and interaction work, so the four challenges must remain in order.

What novice mentors need to understand

  • Controller: the Hummingbird is the connection board. Its prepared R micro:bit acts as the processor/Bluetooth bridge. BirdBlox on the assigned iPad sends the instructions.
  • Input: a sensor reports a value. It does not make anything happen by itself; the program compares that value with a tested threshold.
  • Decision: an IF/ELSE rule chooses what the outputs do. A useful threshold comes from real near/far readings on that exact setup.
  • Outputs: today the visible responses are one single-color LED and one secured position servo with a lightweight pointer.
  • Reset: the safe ready state is LED at 0%, servo at the marked ready angle, program stopped, BirdBlox disconnected, and kit power off.
  • Identity: the kit number, R micro:bit, iPad, full three-word device name, and displayed initials belong together. A green connection dot and active-colored blocks confirm the intended BirdBlox connection.

Build and test every table before students arrive

  1. Function-test one complete set per team: numbered Premium Kit, R micro:bit with BirdBrain firmware, charged iPad, batteries/power, and recorded device name/initials.
  2. Secure an identical capability board at each seat: distance sensor in Sensor 1, single-color LED in LED 1, and position servo in Servo 1 with a lightweight pointer and clear movement zone.
  3. Verify wiring while power is off: sensor yellow = signal, red = +, black = −; LED colored lead = + and black = −; servo white = signal, red = +, black = −.
  4. Prepare and test four files/cards: R1 Connect Check, R2 Read Input, R3 Test Outputs, and R4 Complete Interaction, plus a visible SAFE RESET stack.
  5. Choose two preflighted safe servo angles for the actual rig and mark them on the card. Do not use rotation servos or wheels during this introductory tour.
  6. Stage a port map, startup/reset card, four-box evidence sheet, troubleshooting card, known-good component swaps, inspect bin, and one photo/video fallback per challenge.
Hardware readiness gate: run the physical lane only after the ordered kits arrive and every released set passes the full four-challenge rehearsal. If fewer complete sets work than there are teams, stagger capacity or use the prepared visual/video capability tour for the affected team; never improvise firmware, select a random Bluetooth device, or share loose electronics during the timed block.

Robotics Challenge 2 · Read an input · 10:19–10:44

Objective and mentor anchor

Objective: read controlled distance-sensor values, choose a threshold from evidence, and explain how the input informs code.

Say: “An input reports what is happening. Code reads the value, compares it with a threshold, and decides what comes next.”

Controlled test

  • Keep the target centered in the sensor’s view.
  • Change only distance: far, near, then far again.
  • Record the actual value each time; do not invent a universal threshold.
  • Choose a threshold between the observed near and far ranges, then predict which side should trigger.

Evidence and checkpoint

  • Evidence table contains port, far/near/far readings, chosen threshold, and one observation.

Background knowledge for first-time mentors

The five ideas mentors must understand

  1. Power source: the approved battery or power module supplies energy. Battery type and battery count change voltage, so power sources are not interchangeable.
  2. Light or load: the LED/light module uses the energy. A raw LED is different from a light module that already includes current limiting or other electronics.
  3. Complete path: current needs an uninterrupted route from one side of the power source, through the approved light, and back to the other side. A closed path can light; an open path has a gap and stays off.
  4. Polarity or direction: many LEDs are directional. If the released kit has +/− marks, arrows, keyed plugs, long/short leads, or marked contacts, those exact marks must match the orientation card.
  5. Safe separation: the positive and negative sides must follow their approved routes and must not touch each other directly. An accidental shortcut can bypass the light and may heat or damage the power source.

Useful troubleshooting language

Open circuit
A gap interrupts the path. The light stays off.
Closed circuit
The approved path is complete. The light can turn on.
Continuity
The path is physically connected from one approved contact to the next.
Loose contact
Parts touch only sometimes, so the light may flicker or respond to pressure.
Short circuit risk
The two power sides touch without following the approved light path. Disconnect power; never demonstrate a live short.
Known-good part
A tested battery, light, connector, or complete insert used to isolate one possible failure.

Mentor habit: change one thing, test once, and observe. Randomly changing several parts hides the cause.

Do not improvise the electronics. Use only one final, documented light-and-power combination. Do not substitute a battery, connect a raw LED directly to an unverified power source, omit required current limiting, copy wire colors without checking the actual part, or use the ordered WS2812B addressable strips as though they were a simple two-wire light. Students do not solder.
How mentors should coach: ask “Where does energy start?”, “Trace the approved path with your finger,” and “Where might the gap be?” Give the student the next observable check instead of silently rebuilding the badge.

Before the workday: build one working mentor example

The lead adult completes this protocol with one untouched candidate student kit. Build exactly what a student would build—using the same parts, connection method, directions, and allowed tools. If an adult must use a hidden technique or remember an unwritten step, the student design is not ready.

  1. Start a prototype record.

    Give the design a version name and date. Lay out one exact candidate kit on a clear tray. Record the manufacturer/part name, quantity, voltage or battery count, polarity/orientation marks, connector type, adhesive, badge base, and wearable attachment. Photograph the untouched kit from directly above.

  2. Confirm that the parts belong together.

    Use the product labels or approved specifications to verify the light module’s rated power, whether current limiting is built in or required, the matching power source, and the intended connector/contact method. Do not continue while any part is unidentified or its compatibility is an assumption.

  3. Create a known-good bench set.

    With power disconnected or switched off, inspect the battery holder, light/module, leads, contacts, connector, and insulation. Use only the approved temporary test connection to prove the battery and light work together. Label one tested battery, one tested light/module, and one complete circuit insert “KNOWN GOOD” for later troubleshooting.

  4. Plan the mechanical layout before connecting.

    On the badge base, mark the light position, battery/power position, attachment point, conductor or connector route, and a decoration-free electronics zone. Keep the switch, battery opening, plug, and troubleshooting contacts reachable. Nothing hard or sharp should press toward the wearer.

  5. Dry-fit every part with power off.

    Place the parts without permanent adhesive. Confirm that positive and negative paths stay separated, wires or conductive materials are not pinched, the holder can close, the light faces the intended direction, and the badge can attach without pulling on the circuit.

  6. Assemble slowly and photograph every student step.

    Follow the draft station card. At the end of each step, take one clear close-up from the student’s viewpoint and number it. Record the exact words or marks needed for orientation. Add power last. Do not use an adult-only shortcut that will not be available during the rotation.

  7. Run the first stationary power test.

    Place the badge on the table, not on a person. Recheck the path, orientation, exposed conductor, loose battery, and attachment. Connect or switch on power for the approved short test. Stop immediately for warmth, odor, damage, unstable flicker, unexpected behavior, or a loose power part.

  8. Debug using the student sequence.

    If it stays dark, power off and record the symptom. Check battery seating/switch, final orientation marks, complete contacts, and loose connections; then try one known-good battery and one known-good light/module. Record every confusing instruction or failure point before changing the design.

  9. Secure, insulate, and finish.

    Use only the chosen tested adhesive/fastener. Add strain relief so normal movement does not pull the light, connector, or holder. Cover sharp or loose conductive areas without sealing the switch, battery opening, connector, or inspection points. Decorate only outside the marked electronics zone.

  10. Test normal handling.

    Cycle the approved on/off or open/closed action at least ten times. Attach and remove the badge repeatedly, turn and move it gently, and confirm the light remains steady, the power module stays cool and secure, and no component shifts or presses into the wearer.

  11. Build a second copy from the directions alone.

    Put the first example out of sight. Use a fresh kit and only the numbered step card. Time the build and mark every moment that required memory, guessing, extra tools, or correction. Rewrite the directions and retest until the second copy works without improvisation.

  12. Freeze one approved version.

    Give the passed design a final version name. Keep one untouched master kit, one approved badge, the orientation card, and the exact parts record together. Do not mix later deliveries or substitutions into student kits until the same tests are repeated.

Candidate sample materials

Do not use in this sample

  • The WS2812B strip, micro:bit, AAA pixel pack, or JST harness
  • Decorative embroidery floss as an electrical conductor
  • A loose coin cell pressed directly against an LED
  • Glue, ordinary tape, or decoration as the electrical connection
  • An unverified bare LED or any LED whose required voltage/current limiting is unknown
  • Any cracked, bent, corroded, poorly soldered, damaged, warm, or ambiguously marked component

If the delivered LED board’s required power or built-in current limiting cannot be confirmed from its actual packaging/specification, stop. Do not connect it merely because it resembles the planning photo.

  1. Record the exact delivered parts.

    Photograph the LED front/back, holder front/back, battery label, and thread. Record the LED package/lot and color, holder markings, battery brand/type, and thread used. Keep this sample tied to those exact parts.

  2. Inspect and identify polarity.

    With the battery out and holder off, find the actual + and − marks on the LED board and holder. Reject ambiguous, bent, cracked, corroded, loose, or poorly soldered boards rather than guessing.

  3. Draw two short paths on felt.

    Place the holder and LED where the switch and battery opening remain reachable. Draw one positive route from holder + to LED + and one separate negative route from holder − to LED −. Check both felt sides: the paths must never cross or touch.

  4. Sew the positive route with one thread.

    Keep the battery out. Use several snug, flat loops through the holder + pad and LED + pad, connected by small controlled stitches. Knot and trim the conductive tail so it cannot wander toward the negative route.

  5. Sew the negative route with a fresh thread.

    Use a separate length from holder − to LED −. Make the same snug pad loops and short flat stitches. Do not carry one thread between positive and negative.

  6. Inspect both sides before power.

    Look for crossed stitches, fuzzy bridges, loose arches, long tails, skipped contact pads, or a board that shifts. The circuit fails inspection if it needs finger pressure to maintain contact.

  7. Use an optional adult meter comparison.

    With the battery removed, compare holder + to LED + and holder − to LED − with the known-good sample; each route should show a stable connection while felt is flexed gently. Do not rely only on a continuity beep because conductive thread and meters vary. The two rails must remain separated; an uncertain near-zero path between them is a stop condition.

  8. Run a staged powered test.

    Insert the CR2032 according to the actual holder markings and place the felt flat on a dry, nonconductive surface. Switch on for five seconds, then off. If steady and cool, supervise a one-minute test, then a five-minute test. Stop for flicker, dimming, odor, discoloration, warmth, or battery movement.

  9. Secure parts mechanically.

    After the electrical test passes, use only the approved nonconductive retention method. Do not cover pads, the switch, battery opening, or a problem. Keep hardware from pressing toward skin and add the candidate attachment without loading the stitched paths.

  10. Stress-test the sample.

    Cycle the switch at least 20 times, gently flex the felt 20 times, invert and gently move the badge, attach/remove it repeatedly, and complete a supervised ten-minute wear test. The light must remain steady without squeezing; the battery and boards must remain cool, secure, and comfortable.

  11. Build 3–5 independent copies.

    Repeat with fresh delivered parts and more than one LED if colors/lots differ. Record brightness, build time, resistance/continuity comparison if measured, failures, and repairs. Standardize one known-good part lot/color if behavior differs.

  12. Decide whether students can build it.

    Run the novice timing trial. If full sewing is slow, difficult, or inconsistent, increase mentor preassembly and leave students only the tested placement/connection/personalization steps. Do not invent an untested tape, snap, or connector method merely to save time.

Mentor roles and handoffs

  • Lead mentor / timekeeper: owns the script, visible timer, whole-group cues, one-minute decoration warning, test call, and transition. Does not become absorbed in one repair.
  • Placement/build support: checks kit completeness, keep-clear decoration zones, part placement, and final orientation before connection.
  • Connection/test support: watches the approved no-solder step, first table test, and final secure-power/attachment gate.
  • Troubleshooting/swap lead: controls known-good parts, limits diagnosis to 30–45 seconds, labels symptoms, and quarantines failed electronics.
  • Reset lead, if staffing allows: begins restocking while students finish, clears scraps, restores one full kit per seat, and verifies shared-tool/spare counts.

Roles may overlap, but one named person must own the timer and one named person must own spares/inspect items. Before opening, each person points to the next role in the handoff so a repair never stops the whole rotation.

Rapid troubleshooting for inexperienced mentors

STOP + POWER OFF→LOOK + COMPARE→CHANGE ONE THING→RETEST OR SWAP
  1. Stop movement and remove/open power.

    Ask the student to place the badge flat and stop pressing or bending it. Check for warmth, odor, battery damage, exposed sharp material, crossed paths, or a loose power part. Unsafe work goes directly to the inspect bin and is not retested during the rotation.

  2. Compare with the master example.

    Use the large orientation card and known-good badge. Confirm the same part version, battery seating/switch, keyed plug or contact location, light orientation if required, and complete path. Do not rely on memory.

  3. Check the approved contact once.

    Reseat or press only the connection named on the final station card. Look for a visible gap, decoration between contacts, a loose connector, or conductive material touching the wrong area.

  4. Swap one known-good part.

    Try the known-good battery/power unit first, then the known-good light/module or complete circuit insert. Test after each single change so the failed part can be identified.

  5. End diagnosis at 30–45 seconds.

    If the badge still fails, give the student the approved replacement circuit insert or fresh kit so she can finish. Label the original with the symptom and place it in the inspect bin for later adult repair.

Safety + reset checklist

  • No student soldering and no improvised wiring.
  • No exposed sharp component, crossed path, or unsecured conductive tail.
  • Remove from use any damaged, leaking, warm, mismatched, or questionable battery/power part.
  • Secure the power module and wearable attachment before a student puts on the badge.
  • Use only prototype-approved tools, adhesives, connectors, and insulation.
  • Return shared tools and all loose electronics to labeled containers.
  • Discard scraps; restore one complete matching kit at every seat.
  • Record the symptom on failed parts; never return inspect-bin electronics to stock during a rotation.
  • Count known-good spares and verify that the master kit remains complete.

Workshop readiness decision

Release the workshop only when every item below is true and documented.

  • The final prototype record names every exact component, orientation/contact mark, current-limiting method, student step, mentor-preassembled step, and safe-off condition.
  • The photographed 5–7-step card matches the actual bagged kit and a second adult can reproduce the badge from that card alone.
  • Every mentor passes the build, 45-second circuit explanation, prepared-fault diagnosis, known-good swap, safety gate, and seat-reset practice.
  • Novice construction normally takes 10–12 minutes or less; no ordinary trial depends on an adult completing the build.
  • Most students can finish comfortably within the full 20-minute rotation.
  • At least 90–95% of badges work through normal quick troubleshooting, and recurring failures have been designed out rather than accepted.
  • Ten on/off or open/closed cycles plus repeated attachment/removal do not cause flicker, shifting, warmth, sharpness, or power/attachment failure.
  • Reset between groups is timed, fast, and repeatable; failed electronics cannot return accidentally to student stock.
  • Confirmed headcount, one kit per participant, 10–15% known-good electronic spares, role assignments, master kit, and inspect system are ready.
  • Students can leave wearing a secure, functioning badge and complete the photo/reflection later.

If any target fails: pause release. Simplify the circuit, reduce assembly choices, increase safe mentor preassembly, improve orientation markings/photos, change the component or attachment, and repeat the novice/reliability tests before publishing final directions.
