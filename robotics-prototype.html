Prototype A · Quick Physical Model

Build only enough structure to test the important motion or interaction.

  1. Make a rough base or form

    Use approved cardboard, paper, tape, reusable fasteners, or other released craft materials. Keep it small and easy to change.

  2. Mark component locations

    Label where the input, controller, outputs, battery holder, moving parts, and visitor interaction will go.

  3. Keep access open

    Do not bury the Hummingbird, micro:bit, switches, ports, wires, sensors, or servos inside permanent construction.

  4. Test movement by hand

    Before adding a servo, make sure the hinge, wheel, lever, door, flower, pointer, or other mechanism can move without binding.

  5. Remove unnecessary decoration

    If a detail does not help answer today’s test question, save it for Phase 3.

Question to answer

Does this structure let the sensor detect correctly and the outputs respond without blocked motion or inaccessible parts?

↺OTHERWISE: Return to a safe ready state for the next test.
  1. Power off before hardware changes

    Connect or move sensors, LEDs, and servos only while the Hummingbird system is off.

  2. Connect the minimum parts

    Use one confirmed input and two confirmed outputs. Match ports and component types to the approved plan.

  3. Connect in BirdBlox

    On the team iPad, choose the assigned three-word device name. Verify the connection before opening or changing the program.

  4. Code one condition

    Use the sensor value or dial position to make both outputs respond. Add a safe otherwise/reset behavior.

  5. Test one subsystem at a time

    Confirm the input reading, Output 1, and Output 2 separately before running the complete interaction.

Stop and power off if a servo stalls, a wheel cannot turn, a part becomes warm, a wire is pinched, the structure tips, or the motion could strike someone.
