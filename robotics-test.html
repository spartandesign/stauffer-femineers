Your team finish line

One subsystem improves—and the whole project is safe to restart.

Today is not a race to run the fanciest complete demonstration. Reliable inputs, outputs, mechanisms, mounts, and resets create a stronger January integration.

▱

Mechanisms

◉

Troubleshoot one variable

Use evidence to choose the smallest useful change.

STOP PROGRAM→POWER OFF→MARK ONE VARIABLE→CHANGE→RETEST SAME CONDITION

Input is inconsistent

Keep the visitor action constant. Check sensor direction, distance, environment, mounting, assigned port, and threshold—one at a time.

Servo buzzes or stalls

Power off immediately. Check hand-moved mechanism clearance, alignment, load, linkage, and commanded angle with a mentor.

Output does not respond

Check the assigned port, selected component type, connection, program block, and whether the safe startup state left it off.

Structure tips or twists

Test without powered motion. Move mass, widen or reinforce the base, reduce reach, or revise the mount before reconnecting.

Wires enter motion

Power off. Reroute and secure only the affected wire with enough service slack and no pinch points or tight bends.

Reset is unreliable

Test the otherwise/reset blocks separately. Verify every motor, servo, light, and sound receives a safe return instruction.

A failed test can be complete evidence. If the team identifies the failure condition, preserves safety, tests one change, and records the result, you have made engineering progress.
