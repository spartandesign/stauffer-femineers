BirdBlox connection routine

Use the assigned kit and confirm the green dot before programming.

  1. Inspect while power is off.

    Match the numbered Hummingbird, robotics micro:bit, battery pack, input, outputs, and saved port map. Do not swap micro:bits or load MakeCode.

  2. Power the Hummingbird and open BirdBlox.

    On the team iPad, choose Connect and select the assigned three-word device name.

  3. Confirm the green connection dot.

    If the correct name does not appear or the green dot will not stay on, stop and ask a mentor. Do not choose a nearby team’s controller.

  4. Run the safe startup state.

    LEDs off, rotation servos stopped, position servos at the approved safe angle, and moving zones clear before the interactive program begins.

  5. Know the shutdown routine.

    Return outputs to the safe state, stop the program, disconnect BirdBlox, switch off the kit, and power down before touching hardware.

Choose one high-impact redesign

Use the baseline to find the weakest part of the experience.

Input reliability

Adjust one threshold, sensor direction, mounting location, visitor distance, or environmental shield, then repeat the same trials.

Mechanical reliability

Reduce load, correct alignment, reinforce the base, improve a linkage, limit travel, or reroute one wire away from motion.

Program clarity

Simplify timing, make outputs more distinct, add a safe startup instruction, or make the reset explicit.

Visitor clarity

Improve the cue, label, action location, visible response, safe distance, or the way the invention communicates its future purpose.
