# Limitless Mentor Meeting Decks — 2026–27

These ten PowerPoint decks are the shared-screen facilitation layer for the Limitless meetings. Each slide shows the current time block, what students should do, and the finish line for moving on. Detailed mentor background, pacing, safety, access, and source guidance is in the PowerPoint speaker notes.

## Before each meeting

1. Open the dated deck in PowerPoint and use Presenter View so mentors can see the notes while students see only the slide.
2. Confirm the displayed times and room details still match the day’s logistics.
3. Review the notes for the slides you will facilitate, especially the safety and pathway-specific cues.
4. Keep the deck on the current activity and advance at the next visible time cue.
