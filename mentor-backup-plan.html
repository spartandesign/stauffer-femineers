Wearables · Sew, then code

8:20–10:05 · Circuit Lab

88 activity minutes around snack and return time. Aim for a shared one-LED sample; completion depends on the inspected work.

  1. Demonstrate: trace the complete loop and separate +/− paths on the working example.
  2. Practice: each student makes snug pad loops and a short stitch path on isolated felt.
  3. Build: draw the pair’s simple layout and sew with the battery removed. Inspect both sides and trim loose conductive tails.
  4. Check: queue for a mentor inspection. Only then install the matching battery and test. Save each student’s contribution and observation.
  5. Stop: remove power before repairs. Collect/count needles for snack and at the end. A persistent fault moves to INSPECT; use a complete spare.

Fast finishers annotate the loop and explain an unpowered fault sample. Students needing more time save their practice and explain the mentor example.

Two-LED fallback when movement is not ready

Disconnect unused motion hardware with power off. Use kit LEDs in LEDS 1 and 2; record the input and its tested comparison. Rehearse this finite block recipe before handing it to students:

  1. On start, set both LEDs to 0.
  2. If the selected sensor condition is true, set LED 1 to 50 and LED 2 to 0; otherwise set LED 1 to 0 and LED 2 to 50.
  3. Wait one second, then set both LEDs to 0. Run again for each test condition.

This has two output devices, both of the same type. Mark motion exploration deferred if no servo was tested. If no sensor is ready, a mentor may prepare a micro:bit-button input using BirdBlox’s Buttons lesson; otherwise record observation and the missing-input test.

Normal shutdown: let the one-shot challenge finish; use the rehearsed SAFE RESET, allow motion to settle, Stop, disconnect, and power off. With the two-LED setup, the reset sets both LEDs to 0. For unexpected motion, heat, odor, or a jam, stop code if possible and power off immediately; keep hands clear and do not command another movement.

Wearables: Glowing Pin

Jennifer · W1–W3 · Allow 10–20 minutes within Circuit Lab, before the 10:05 needle count. Give your inspected one-LED felt practice sample a character, symbol, or message. Work with your practice partner; extra individual electronic sets are not assumed.

  1. Sketch a simple felt shape around the existing LED and explain what its light means.
  2. Use the SparkFun Glowing Pin illustrated tutorial for design inspiration. Keep our mentor-tested holder, LED, polarity, and separate conductive paths; the tutorial hardware and LED orientation may differ.
  3. Remove the battery before adding stitching or trimming. Keep decorations clear of conductive paths and leave the holder accessible.
  4. Have Jennifer inspect both sides again before powering and testing. Add a pin back only if one is available and the mentor approves secure attachment clear of the circuit. Otherwise keep a flat glowing felt sample.
  5. Save a photo and one sentence about your design. Return and count needles by 10:05, even if unfinished.

Materials: existing felt circuit, spare felt, marker, and counted sewing tools; pin back optional and not confirmed in stock. This coin-cell activity uses no micro:bit and remains separate from the October 13 badge event.

Creative Robotics: Robot Mood

Stephanie · R1–R3 · Allow 10–15 minutes after core trials, ending by 11:09. Make the same two LEDs communicate two different moods or messages using your already-tested input. A moving part is not needed.

  1. Choose two meanings, such as welcome/wait or calm/excited. Sketch a face on paper if paper is available; the LEDs can remain on the table.
  2. Keep the mentor-tested sensor, threshold, and ports. Predict which message each of the two test conditions should produce.
  3. Adapt the two-LED recipe: for one condition, light LED 1 steadily for one second; for the other, blink LED 2 twice, using 0.25 seconds on and 0.25 seconds off. Use the mentor-approved brightness, start with both LEDs at 0, and finish with both LEDs at 0. Run once per test.
  4. Swap Driver/Navigator. Test both conditions, ask another pair to interpret the messages, change one pattern, and retest.
  5. Save the code and a short observation. Use the rehearsed reset, disconnect, and power off for the 11:09 transition.

Materials: assigned Hummingbird Bit, iPad/BirdBlox, tested input, and two kit LEDs; optional paper and marker. Use the prepared button-input fallback only if Stephanie has tested it, and label sensor work deferred. A servo extension requires a separately secured, tested setup released by the mentor.
