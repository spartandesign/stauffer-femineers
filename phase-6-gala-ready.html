Two-test reliability rule

A single successful demonstration is not yet Gala-ready.

1Set upUse only the labeled project container, project card, and planned position.
→
2DemonstrateRun the complete experience exactly as it will happen publicly.
→
3ResetReturn to the safe ready state without mentor rescue.
→
4RepeatRun the same setup and demonstration a second time.
→
5RecoverExplain and practice the safe backup if a known failure occurs.
Pass twice: both complete trials must meet safety, function, comfort or stability, visitor clarity, reset, and shutdown expectations. If either trial fails, make one critical repair and start the count again.
