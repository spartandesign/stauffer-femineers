Prepare the hardware before student use.

  1. Label and load firmware. On a Windows laptop, follow BirdBrain’s official Setup module and current firmware link. Disconnect USB after transfer. Record the full Bluetooth name and its three displayed initials on the kit/iPad card.
  2. Connect while power is off. Match the port map below to the actual printed labels. The single-color LED and distance sensor use screwless terminals; insert with the supplied terminal tool and check that wires are secured.
  3. Secure the mechanism. Use a position servo, not a rotation servo. Establish its ready position with the mechanism clear; power off before attaching a lightweight pointer. Mount the servo on a stable base and mark the motion zone.
  4. Choose two safe positions. Tri tests HOME and ACTIVE on that mounted rig, checking clearance, load, and direction. Enter those actual angles in every starter. No universal classroom angle is supplied here.
  5. Pair and measure. In BirdBlox, select only the assigned device. Confirm the green connection dot and active robot blocks, then measure a centered target far → near → far. Choose a threshold between stable near/far ranges.
  6. Build the four starters. Use the block recipes below to create R1–R4 and a separate SAFE RESET program on each iPad. Rehearse every challenge and a normal shutdown; record a short whole-system backup video.

BirdBlox starter blocks to assemble.

These are readable block assembly recipes, not screenshots or importable BirdBlox files. Choose the real blocks in BirdBlox, select the assigned robot in each, and replace HOME, ACTIVE, and T with your measured numeric values. No JavaScript conversion is needed. The one-second waits are starting values; increase them if the tested mechanism needs more settling time.

Prepare before class: create and physically test these programs on the actual iPads. The webpage cannot verify a Bluetooth connection, servo clearance, or sensor threshold. Leave the movement programs unused until those checks pass.

SAFE RESET · separate saved program

Use this when normal control is available. It returns the pointer to its pretested ready position; it is not an emergency stop.

when green flag clicked
Bit LED · port 1 · brightness 0%
Bit Position Servo · port 1 · angle HOME
wait 1 seconds

At a normal transition, let the one-shot challenge finish (or stop its script), open SAFE RESET, run it, and wait for the pointer to settle. Then tap Stop, disconnect BirdBlox, and switch kit power off. No other script should be commanding the servo.

R1 Connect Check

Start with the same flag → LED 0 → servo HOME → wait stack as SAFE RESET. Confirm the right kit responds, then have both partners rehearse connection and shutdown.

R2 Read Input

Place a Bit Sensor reporter from Robots in the workspace; choose Distance and port 1. Tap the reporter to read its value. This is a reporter, not a stack under a green flag.

Bit Sensor · Distance · port 1

R4 Complete Interaction

Place the target, then tap the green flag. The program samples distance once after resetting, responds for one second if near, and returns to ready. Move the target and tap the flag again for a new trial; this starter has no forever loop.

Bit LED · port 1 · brightness 50%

Bit Position Servo · port 1 · angle HOME

Bit LED · port 1 · brightness 0%

The IF/ELSE comes from Control; the less-than comparison comes from Operators. In BirdBlox, the nested blocks fit inside the IF/ELSE shape—“end if” is a reading aid here, not an extra block. At a reading equal to T, the else branch runs.

Recover deliberately.

SymptomMentor response
No connection / red dot / gray blocksCheck kit power, iPad Bluetooth, and exact device identity; disconnect and reconnect only the assigned device. Ask Tri to inspect firmware or board seating with power off.
Unexpected kit movesStop the script and switch off the affected kit. Verify device name, selected robot, and labels before reconnecting.
No or unstable distance changeConfirm Distance/port 1, wire labels, and a centered target. Re-measure; do not copy another team’s threshold.
LED or servo does not respondStop and power off before checking the selected port, wire orientation, and supply. Use a known-good component or complete spare.
Buzzing, stalling, blocked pointer, warmth, or unstable movementIf control is available, stop the code; switch Hummingbird power off immediately. Keep hands clear until motion stops, then disconnect BirdBlox and inspect. Do not run a movement reset into a fault or force a powered servo.
Incomplete kit or persistent faultUse the complete spare or a recorded capability tour; label the failed set INSPECT and record which evidence was observation only.
