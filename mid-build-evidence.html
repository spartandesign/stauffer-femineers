Troubleshooting note

Explain the evidence in five short statements.

1. Subsystem: I/we tested _____.

2. Success meant: The test would pass if _____.

3. First result: Instead, I/we observed _____.

4. Controlled change: I/we changed only _____ because _____.

5. Retest: The second result was _____, which shows _____.

January restart card

Write an instruction—not a reminder.

Too vague

“Finish it.”

“Fix lights.”

“Keep working on robot.”

Actionable

“With the battery out, resew the loose negative pad on LED 3, ask for inspection, then repeat the gentle-movement test.”

“Power off Kit 4, realign the left servo linkage, hand-test clearance, then repeat the 30°–90° position test.”
