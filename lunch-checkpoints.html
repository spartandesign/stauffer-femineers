Three Wednesday lunch checkpoints · Room 14

Deliver. Demonstrate. Celebrate.

Short lunch checkpoints keep projects moving between full workdays. Submit first, demonstrate what is ready, receive a clear status, and leave knowing exactly what to do next.

Lunch meeting time: 12:29–12:59 p.m. in Room 14. Canvas work is reviewed before the meeting so the mentors can concentrate on students who need decisions, revisions, or help.

Wednesday, October 21, 2026

Design Ready checkpoint

Submit the complete Phase 2 package by Monday, October 19. Mentors review it on October 20.

Bring or open

  • Approved proposal and revisions
  • Labeled drawing and pathway system diagram
  • Storyboard or lighting sequence
  • Materials and fabrication request
  • Tinkercad link, STL, or SVG when needed
  • Prototype question and three trial test plan
  • Individual reflection

Demonstrate in sixty seconds

  1. Show the design evidence.
  2. Explain one important decision.
  3. Name the first November test.
  4. State your next action.

Earn green status

Complete, understandable, on time, and ready to build. Yellow projects revise one item. Red projects meet with a mentor before materials are released.

Wednesday, December 2 · Project Rescue: This is an invitation only support lunch for yellow and red projects. Bring the blocker, current evidence, and the exact decision or item needed before the December 7 workday.

Wednesday, January 13, 2027

Restart Ready checkpoint

No construction is required during winter break. Use the December evidence to prepare for January 25.

Submit before lunch

  • Current project status photo
  • Most recent test result
  • Confirmed code backup and file name
  • Missing, damaged, or untested materials list
  • Three prioritized January 25 tasks
  • One blocker or mentor question
  • Individual completion commitment

Demonstrate in sixty seconds

  1. Show where the project stopped.
  2. Explain what the last test revealed.
  3. Name the first January 25 action.
  4. Request the exact help or material needed.

Finish line

Every project has a verified restart plan, prepared supplies, a code backup, and a realistic integration goal for January 25.

Wednesday, February 10, 2027

Gala Path checkpoint

This check happens before the February break so mentors can prepare repairs and supplies for the February 22 final workday.

Submit before lunch

  • Current overall project photo
  • Latest complete system test result
  • Critical, important, and optional punch list
  • Repair and replacement request
  • Draft project card
  • Safe demonstration or backup plan
  • Individual presentation responsibility

Demonstrate in sixty seconds

  1. Show the current project condition.
  2. Explain the greatest Gala readiness risk.
  3. Name the one critical February 22 task.
  4. Practice the opening line of the project story.

Finish line

Mentors know what to repair, replace, print, charge, fabricate, or simplify before the final workday.

Students who submit on time, complete the checklist, show genuine evidence, demonstrate, and name the next action may choose a full size candy bar, another individually packaged snack, or a nonfood prize.

✓

Reward readiness

Recognize preparation, honest evidence, and responsibility rather than comparing project polish.

↻

Students still receive feedback and may complete the required correction.

♡

Keep it inclusive

Offer ingredient labeled and nonfood choices plus reasonable make ups for excused absences, accommodations, or verified access problems.
