Jennifer · W1–W3 · 18 students

Sew a circuit. Program a response.

1. One-LED felt practice

  1. Trace the positive and negative paths on your mentor’s working example.
  2. Practice sewing a pad connection. Share the circuit parts; both partners take a turn.
  3. Sew separate paths with the battery removed. Ask for an inspection before power is installed.
  4. Test, explain what happened, and save a labeled photo. A useful in-progress sample counts.

LED lesson · Stitching lesson

2. A helpful micro:bit interface

  1. Use your W-labeled board and laptop. Start with A → heart, B → happy face, A+B → clear.
  2. Switch the keyboard role so each partner downloads and tests.
  3. Change the symbols for a real user: ready/help, welcome/wait, or two useful messages.
  4. Try A, B, and A+B three times. Improve one thing and retest. Save code and a screenshot.

Stephanie · R1–R3 · Nine pairs

Make an invention respond.

  1. Connect and identify. Use your assigned R-labeled Hummingbird Bit and iPad. Record the kit name, input, ports, and reset.
  2. Explore a change. Measure two conditions with the mentor-selected sensor. Explain how the reading changes. Use only the threshold and setup tested for your kit.
  3. Build an interaction. Program one input to change two outputs. Use LEDs and a securely mounted position servo when released by your mentor; the fallback uses two kit LEDs.
  4. Test and improve. Predict a response, run three trials, change one thing, and retest. Swap Driver/Navigator after each challenge. Explain the ready state and how to reset.

Two LEDs are two outputs of the same type. If movement is deferred, record that accurately and identify any later mechanism test your proposal needs.
